# Review checklists — накопительный справочник

Что смотреть в диффах по темам. Растёт по мере стадий — после
каждого ревью добавляем новые находки и паттерны.

## async / гонки / порядок

- Кто назначает порядок? Одна точка упорядочивания или каждый
  решает сам?
- Что при дубле сообщения (ретрай сети, redelivery pub/sub)?
  Apply идемпотентен или состояние плывёт?
- Гап в seq — обнаруживается? Чем лечится (resync? refetch?)?
- Сообщение пришло ДО того, как мы joined — что видит клиент?

## память / утечки

- Каждый `addEventListener`/`subscribe` имеет пару — cleanup в
  `useEffect` return / `dispose` / `OnDisconnected`?
- Таймеры (`setInterval`, `setTimeout`, heartbeat) — кто их гасит?
- Замыкания в колбэках — что они держат живым?
- Растущие коллекции без потолка (history, received-queue, offline-buffer)?

## рендер / перформанс фронта

- Что триггерит кадр? Полная перерисовка vs dirty-rect/regions?
- React-стор пишется на каждый op → re-render storm?
- Работа на кадр: аллокации в draw-цикле (новые массивы/объекты → GC)?
- Хит-тест: O(n) скан по всем объектам на каждый mousemove?

## сеть / reconnect

- Что происходит с in-flight op'ами при обрыве WS?
- Есть ли offline-очередь и что с ней при reconnect
  (rebase? refetch? drop)?
- Backpressure: канал заполнен — что теряем и как узнаём?
- Heartbeat: кто замечает мёртвого пира и когда?

## консистентность / merge

- Merge детерминирован на всех репликах? Источник недетерминизма:
  порядок обхода Dictionary/Map, float-сравнения, `Date.now()` на клиенте?
- LWW: чьё «last» — клиентское время (нельзя!) или серверный seq?
- Replay журнала: применяются ли ops дважды (snapshot уже содержал их)?
- Fractional index: строковое сравнение стабильно локаль-независимо?

## масштаб / scale-out

- Состояние комнаты в памяти — что при рестарте/миграции?
- Pub/sub фанаут: N комнат × M инстансов — кто фильтрует?
- Одна точка упорядочивания всё ещё существует при >1 инстансе?

## выделение / жесты (находки T-36..T-38)

- Lock/ограничения покрывают ВСЕ мутационные пути, а не только
  очевидный: жесты, клавиатура (delete/nudge/align/dup/reorder),
  inspector, marquee, Ctrl+A. Побочный путь выделения (layers-
  панель) обходит hitTest — гейтить надо точку мутации, не точку
  выделения.
- Групповые жесты: orig-map и pivot строятся из фильтрованного
  множества — locked-sibling не должен ехать с группой.
- Help/`?`-панель — тоже код: хинт про хоткей, который не подключён,
  = баг документации. Каждый хинт проверять по обработчику.
- Uncontrolled input + remote-правки: `key` должен включать значение
  пропа, иначе панель показывает протухшие числа навсегда.
- Esc/отмена жеста: реверт только gesture-ключей — полный откат
  orig-props затирает remote-правки, сделанные во время драга.

## ИИ-почерк (собрано из внешних аудитов — greptile/sailop/SynthScan, 2026)

Проверять при каждом ревью — один признак ничего не значит,
четыре+ = паттерн:

| Телл | Что искать | Статус у нас |
| --- | --- | --- |
| Коммент-нарратив | `// increment counter` над `counter++`; коммент пересказывает строку | чисто (комменты у нас — why/T-теги) |
| Чужие иероглифы | язык доков не тот — был вьетнамский в tasks.md/CHANGELOG | вычищен 2026-11-10 |
| Копипаст-блоки | 3+ идентичных сниппета без хелпера — `getElementById(...) as X` был ×9 | сведено к `field(id)` |
| Расходящиеся конвенции | `interface`/`type` микс, camelCase/snake_case по файлам | консистентно |
| Церемонный try/catch | обёртка вокруг кода, который не бросает; голый вызов рядом | catch'и у нас — осмысленные degrade |
| Каст-костыли | `as any`, `as unknown as X` | чисто |
| Тесты-фантомы | `Assert.True(true)`, тест мокает то, что проверяет | реальные (bot+xUnit) |
| JSDoc на ровном месте | док на каждый приватный метод без смысла | C# /// — только design-rationale |
| Хедеры вручную | fetch с рукописным Authorization там, где есть обёртка | сведено к authedFetch |
| Пустой useEffect | `useEffect(() => {}, [])` заглушка | нет |
| Генерические имена | `data`, `result`, `handler`, `manager`, `temp`, `item` | `obj` — натуральный локал, ок |
| Пере-аннотация | `useState<string>('')` для выводимого типа | все union/nullable — нужны |
| Унифицированная свежесть | файл целиком «взрослый» в одном коммите | история инкрементальная |
| Хак-фикс вместо корня | пин версии / удалить проверку вместо починки | слежим (находки честно пишутся) |

Класс, который уже дважды ловили живьём — **auth-follow bug**:
UI зовёт защищённый эндпоинт без токена/гранта (unlist, /docs,
/ops, blobs). Правило: **любой fetch до auth-защищённого пути —
только через authedFetch (+grant в query где нужно)**.
